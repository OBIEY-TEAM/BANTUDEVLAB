{% trans "Qu'est-ce que l'authentification Zero-Trust ZKP et pourquoi surpasse-t-elle les mots de passe classiques ?" %} {% icon "chevron-down" size=18 %}

{% trans "ZKP (Zero-Knowledge Proof, ou preuve à divulgation nulle de connaissance) est un protocole cryptographique mathématique fondé sur le problème du logarithme discret (RFC 3526 MODP 2048 bits). Grâce au protocole de Schnorr rendu non-interactif via la transformation de Fiat-Shamir, vous prouvez au serveur que vous détenez votre secret mathématique sans JAMAIS lui révéler ce secret, ni même le faire transiter sur le réseau." %}

{% trans "Avantages majeurs :" %}

  • {% trans "Même en cas de compromission totale de la base de données du serveur, aucun mot de passe ni clé privée ne peut fuiter, car seules les clés publiques sont enregistrées." %}
  • {% trans "Immunité intégrale contre les écoutes réseau et le rejeu de requêtes grâce aux nonces éphémères consommés atomiquement." %}
  • {% trans "Validation mathématique stricte de non-appartenance aux petits sous-groupes pour éliminer toute tentative de falsification de clé." %}
{% trans "Comment fonctionne la double approbation ZKP sur les Merge Requests (MR) ?" %} {% icon "chevron-down" size=18 %}

{% trans "Pour les projets critiques des ministères, banques centrales et agences publiques, BANTUDEVLAB intègre un quorum d'approbation cryptographique :" %}

  • {% trans "La fusion (merge) d'une branche de fonctionnalités vers la branche principale exige la signature mathématique d'au moins deux relecteurs habilités." %}
  • {% trans "Chaque approbation est scellée par une preuve ZKP enregistrée sous le modèle SovereignMergeRequestApproval." %}
  • {% trans "Le pipeline GitLab CI/CD et la passerelle de fusion bloquent automatiquement l'opération si le quorum cryptographique n'est pas réuni." %}
{% trans "Comment l'assistant IA local Gemma 5B audite-t-il le code sans aucune fuite vers l'étranger ?" %} {% icon "chevron-down" size=18 %}

{% trans "Contrairement aux assistants cloud propriétaires hébergés sous juridiction étrangère (Cloud Act, FISA), le modèle Gemma 5B de BANTUDEVLAB :" %}

  • {% trans "Est déployé exclusivement sur des serveurs physiques situés sur le sol africain (Systalink Cloud, datacenters Tier-3 Abidjan, Dakar, Nairobi, Kigali)." %}
  • {% trans "S'exécute en local via vLLM / Ollama sans aucune transmission de télémétrie ou de code source à des tiers." %}
  • {% trans "Masque et anonymise automatiquement les secrets éventuels avant toute journalisation (AIInteractionLog)." %}
  • {% trans "Est fine-tuné avec LoRA/QLoRA (4-bit GGUF) sur les cadres légaux panafricains et les meilleures pratiques de souveraineté logicielle." %}
{% trans "Comment fonctionne le scanner de sécurité SAST et comment est calculé le score de souveraineté ?" %} {% icon "chevron-down" size=18 %}

{% trans "Le scanner d'analyse statique SAST de BANTUDEVLAB analyse automatiquement chaque commit et fichier soumis :" %}

  • {% trans "Détection des secrets codés en dur (clés privées, tokens API, identifiants)." %}
  • {% trans "Détection des injections SQL, exécutions de commandes non sécurisées (eval, exec, pickle)." %}
  • {% trans "Détection des dépendances externes non souveraines ou non auditées." %}
  • {% trans "Attribution d'un score de 0 à 100 : un score inférieur à 70 peut déclencher un blocage automatique préventif dans les hooks de pre-receive." %}
  • {% trans "Exportation des rapports aux formats standard OASIS SARIF 2.1.0 et GitLab SAST (gl-sast-report.json)." %}

{% trans "Pourquoi la plateforme n'utilise-t-elle aucun emoji ?" %} {% icon "chevron-down" size=18 %}

{% trans "BANTUDEVLAB applique une politique stricte Zéro-Emoji (contrôlée en continu par le script scripts/check_no_emoji.py) pour trois raisons majeures :" %}

  1. {% trans "Accessibilité universelle (WCAG 2.2 AA) : les lecteurs d'écran pour personnes malvoyantes prononcent souvent de façon erratique les pictogrammes Unicode." %}

  3. {% trans "Cohérence d'affichage : affichage strictement identique quel que soit le système d'exploitation client (Linux, BSD, Windows, macOS, terminaux mobiles)." %}
