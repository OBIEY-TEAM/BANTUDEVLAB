## 4. Stack Technique du Projet (Architecture Souveraine 100% Permissive)

| Couche | Technologies & Outils | Rôle & Usage | Licence |
| :--- | :--- | :--- | :--- |
| **Noyau Applicatif & API** | Python 3.12 / Django 5.2 & DRF | Architecture backend, modèles de données, API REST et vues d'authentification | BSD-3-Clause |
| **Moteur Forge Git** | Gitea CE 1.22 (Go) | Moteur Git distribué, gestion des dépôts, branches, commits, PR et webhooks | MIT |
| **Cryptographie Zero-Trust** | Protocole Schnorr NIZKP (RFC 3526) | Preuves non-interactives Fiat-Shamir sur groupe 2048-bit, génération BIP-39 (12 mots), tokens Git signés, aucun mot de passe | Propriétaire CYBERSOCLE (MIT) |
| **Scanner de Sécurité SAST** | Python AST & Entropie Shannon | Détection de fuites de secrets ($H \ge 3.8$), détection de failles, calcul du score de souveraineté ADSS-v1, exports OASIS SARIF 2.1.0 et GitLab SAST | Propriétaire CYBERSOCLE (MIT) |
| **Copilote IA Souverain** | Google Gemma 2 2B & Ollama | Modèle IA local on-premise quantifié Q4_K_M GGUF, revue de code, explications et streaming SSE sans fuite de données | Ollama (MIT) / Gemma Terms (Inférence locale) |
| **Base de Données** | PostgreSQL 16 & PgBouncer | Stockage relationnel persistant et pooler de connexions haute performance | PostgreSQL License |
| **Cache & Broker Async** | Valkey 7.2-alpine & Celery 5.4 | Cache distribué en mémoire (remplacement BSD-3 de Redis) et exécution des tâches périodiques/asynchrones | BSD-3-Clause |
| **Serveur Web & Reverse Proxy** | Nginx 1.27-alpine | Terminaison TLS 1.3, CSP stricte sans CDN externe (`default-src 'self'`), isolation et routage des services | 2-Clause BSD |
| **Frontend & UI / UX** | Vanilla JavaScript ES6+ & CodeMirror 5 | Éditeur de code intégré, terminal de commande pro sans saisie libre, composants SVG Primer (zéro emoji, zéro CDN) | MIT |
| **Internationalisation (i18n)** | GNU gettext (`.po` / `.mo`) | Traduction complète et synchronisation instantanée en 4 langues (Français, Anglais, Kiswahili, Portugais) | Permissif |
| **Intégrité & Audit Trail** | Chaînage cryptographique SHA-256 | Journal d'audit immuable (`previous_hash -> hash`) conforme aux exigences de la Convention de Malabo 2014 | Propriétaire CYBERSOCLE (MIT) |
| **Hébergement & Domaine** | VPS Ubuntu 24.04 LTS & Systalink Cloud | Domaines de production officiels achetés chez Systalink / Datacloud (`cybersocle.site`, `git.cybersocle.site`) | Infrastructure Cloud |
| **Qualité, Tests & CI/CD** | Pytest, Playwright, Ruff & Bandit | Couverture de tests automatisés (> 95%), tests E2E navigateur Chromium, linter PEP 8 et analyse SAST CI | MIT / Apache 2.0 |
